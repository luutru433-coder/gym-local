# Animation pilot provenance

All geometry, materials, node names, rig metadata, keyframes, and equipment-prop declarations in this pilot are deterministically materialized from `source.json` by `scripts/animation-pilot-assets.mjs`.

The source was authored by Gym Local contributors for this repository. It does not contain downloaded, scraped, traced, marketplace, generative, font, texture, image, audio, or third-party model data. Releases `1.0.0` and `1.0.1` are MIT-licensed for offline redistribution; their only intentional differences are the semantic version and declared release sentinel/metadata.

Compatibility review fields use the automation record `automation.animation-pilot-01-rev-02` dated 2026-09-05. This is deterministic compatibility metadata and does not claim that an optional human review occurred.
