# Code review checklist

- Does the change stay inside its stated module and use public contracts?
- Can a catalog, template, or formula update alter historical user data?
- Are equipment-specific history, load mode, and PR rules preserved?
- Do offline and failed-network states remain usable?
- Are migrations transactional and backups still restorable?
- Are external content source, author, license, and review fields complete?
- Are touch targets, keyboard focus, VoiceOver labels, contrast, and reduced motion covered?
- Were the affected tests and the required full checks run?
